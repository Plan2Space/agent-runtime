# agent-runtime — instruções do agente

## Política de SPECs e skills (obrigatória)

Todas as SPECs e skills do ecossistema Plan2Space são mantidas exclusivamente em `Plan2Space/claude-engineering-skills`. Nenhuma SPEC nova pode ser criada fora desse repositório. Toda alteração de SPEC deve ser feita na fonte central e referenciada por este repositório.

- Não crie arquivos de SPEC aqui (`docs/specs/`, `specs/`, `.claude/specs/`).
- Skills são consumidas por referência versionada, nunca copiadas como fonte.
- Governança: `specs/governance/SPEC-001-centralized-engineering-governance.md` no repositório central.
- Pendências, débitos e estados ficam em GitHub Issues e no Project Board deste repositório.
